## 4. 安装步骤

1. 从 Steam 官方页面安装 Steam 客户端。
2. 登录自己的 Steam 账号。
3. 打开 Rusted Warfare 商店页并购买游戏。
4. 点击安装。
5. 安装完成后，在 Steam 中右键游戏，选择“管理” → “浏览本地文件”。
6. 记录安装目录，并确认其中存在 `assets/` 目录。

常见安装目录示例：

```text
<SteamLibrary>\steamapps\common\Rusted Warfare\
```

实际路径以 Steam 的“浏览本地文件”为准。

## 5. 与本项目的关系

安装后需要找到：

```text
<Rusted Warfare install>\assets\
```

该目录用于 RWPP 无头服务端。不要把 `assets/` 提交到 Git 仓库。

建议只在本机或隔离环境中使用自己的合法游戏副本，并遵守游戏 EULA。

## 6. 不要使用第三方安装包

不建议从以下来源下载 PC 安装包：

- 网盘转载。
- 破解站。
- 未知 EXE/MSI 下载站。
- 非官方 APK 聚合站。

这些来源存在恶意软件、版本不匹配和版权风险。PC 版应以 Steam 官方渠道为准。

## 7. 是否存在 PC 试玩版

在 2026-11-04 查询 Steam App `647960` 时，API 未返回 PC demo 条目。官方页面展示的是 Android 试玩版，不等同于 PC 无头训练环境。

如果后续出现官方 PC demo，应重新核对来源和版本。
