# 铁锈战争经济与建筑系统架构方案

> 作者：周培智  
> 版本：v1.0.0  
> 适用：PC 版《铁锈战争》（Rusted Warfare 1.15）  
> 目标：从纯战术 Micro 对抗迈向包含经济采矿、建筑建造与工厂产兵的完整 RTS 决策闭环。

---

## 1. 为什么必须采用分层架构（Hierarchical Architecture）？

在即时战略（RTS）游戏中，微观操作（Micro）与宏观运营（Macro）具有截然不同的时空特性：

| 特性 | 微观战术 (Micro Tactical) | 宏观运营 (Macro Strategic) |
| :--- | :--- | :--- |
| **决策频次** | 高频：2 ~ 10 Hz（每 0.1~0.5 秒一次） | 低频：0.3 ~ 1 Hz（每 1~3 秒一次） |
| **动作空间** | 空间位移、目标集火、拉扯走位 | 离散槽位选址、科技升级、产兵排队 |
| **奖励反馈** | 密集反馈：血量差值变化、击杀收益 | 严重长延迟：投资矿井在数十秒后才体现为部队优势 |
| **直接暴力 RL 的下场** | 可以在几百轮内学会风筝和集火 | 动作空间呈组合爆炸，严重稀疏奖励导致 PPO 策略崩溃或瘫痪 |

**结论**：借鉴 DeepMind AlphaStar 和腾讯 TStarBots 方案，采用**宏观战略规划（Macro Planner） + 战术微操网络（Micro PPO） + 底层安全执行器（Execution Layer）**的三层解耦架构。

## 3. 铁锈战争核心经济与建造规则规范

1. **资金池（Credits）**：
   - 全局单货币体系，建造与生产均即时扣除。
   - 基础收入：每秒被动回金。
   - 矿井（Extractor）：必须坐落在地图预置的 Resource Pool 上，提供主要经济来源（T1: +8/s, T2: +18/s）。
2. **建筑体系（Buildings）**：
   - 提取器（Extractor）：固定矿位槽位，具备 T1/T2 升级链路。
   - 陆军工厂（Land Factory）：平地自由建筑，拥有独立的生产队列与生产计时器。
   - 防御炮塔（Turret）：固定阵地防御，自带独立警戒与索敌攻击逻辑。
3. **单位生产管线（Production Pipeline）**：
   - 工厂接收生产请求并加入排队。
   - 队列满或资金不足拒绝指令。
   - 生产时间结束后，新单位从工厂出口下线并自动编组进入战斗部队。

## 5. 训练与闭环评估方案

1. **宏微融合环境 (`MacroMicroEnv`)**：
   - 战术微操策略复用已有的 PPO 智能体。
   - 宏观控制器负责在后台维持经济运转与部队源源不断地供给。
2. **端到端训练与推理闭环**：
   - 训练模式：PPO 在动态兵力供给环境下学习持续对抗。
   - 推理与评估模式：一键加载模型，对抗内置 Scripted AI，输出完整对局结果、胜率及回放文件。
